# Aster Hotel mobile

Ứng dụng Flutter dùng Riverpod, go_router, Dio và secure storage. Source được chia theo tính năng trong `lib/features`; theme, API, model và provider dùng chung nằm ở `lib/core`.

Xem `../README.md` để chạy API SQL Server, xem mật khẩu demo, chạy Flutter Web hoặc Android và thực hiện kiểm thử. Dùng `../scripts/flutter.ps1` từ thư mục gốc để tránh lỗi Flutter LSP với đường dẫn Unicode trên Windows.
